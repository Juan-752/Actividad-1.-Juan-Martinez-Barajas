# Actividad-1.-Juan-Martinez-Barajas

EN EL README, EXPLICA COMO DESARROLLARÍAS UNA PEQUEÑA APLICACIÓN O JUEGO
// Problema, plataforma y lenguaje elegido:
  -Pues empezaría ideando el juego, trataría de un perro, que intenta cruzar la carretera, para llegar a un hueso, que se encuentra en la otra acera, y tendría que      esquivar vehículos continuamente, y así subiendo de nivel, y ya sea cada nivel que, o los coches van más rápido, y los cruces son más difíciles, al ir acabando el    juego, el perro acabaría logrando el objetivo de conseguir el hueso. Lo desarrollaría en Visual Studio Code con Java.

// Algoritmo o ejemplo de paradigma que utilizarías:
  - Pues el algoritmo del juego se basaría en niveles, vas subiendo continuamente de nivel, y conforme subes, más difícil será, pero cuanto más subas, mejores          recompensas se logran, ya sean skins para el animal, el paisaje, etc... Obviamente si pierdes, recibirás las recompensas anteriores, pero ya tendrías que empezar     de nuevo, y no podrías conseguir las recompensas de los niveles pasados anteriormente. Quiero que cada nivel esté separado dentro del código para que esté mejor      organizado.
// Como llega el código a ejecutarse:
  - Se ejecutaría em Java, y habría un lanzador oficial con aplicación de escritorio que te redirigía directamente a página de juego.
